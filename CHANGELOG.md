# Changelog - ArcadeLedMarquee

## [Unreleased]

### Added

* Initial dedicated Recalbox firmware.
* SD-based `/config.txt` setup for WiFi, DHCP/static IP, brightness, matrix viewport, and playback timing.
* Minimal `/gif` HTTP input for Recalbox events.
* `/gif/default.gif` playback before game launch and after game exit.
* Game GIF variant rotation, for example `dkong_1.gif`, `dkong_2.gif`, and `dkong_3.gif`.
* Scrolling title fallback when no game GIF exists.
* Recalbox EmulationStation userscript.
