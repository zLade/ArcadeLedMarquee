# GIF Folder

Put `default.gif` here:

```text
/gif/default.gif
```

Create one subfolder per Recalbox system id, then put numbered game GIF variants inside it:

```text
/gif/fbneo/dkong_1.gif
/gif/fbneo/dkong_2.gif
/gif/fbneo/dkong_3.gif
```

The firmware ignores unnumbered game GIFs such as `dkong.gif`.
